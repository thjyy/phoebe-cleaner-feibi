# V10 动作类型分镜

本目录用于解决 V8/V9“同一套站立进食骨架只更换特效”的问题。V10 候选方案必须同时改变删除方式、身体重心、主要道具和退场结构。

| 编号 | 动作类型 | 核心动作差异 |
| --- | --- | --- |
| 01 | 帽子代吃 | 帽子离体、追逐拉扯、帽子吞文件、倒栽回帽子 |
| 02 | 文件果汁车 | 推车、投料、摇动曲柄、坐姿吸饮、骑车离场 |
| 03 | 逃跑文件追捕 | 空降、扑空滑行、罩子捕获、跪坐进食、罩子滑走 |
| 04 | 魔法下午茶 | 杯中入场、坐姿施法、倒茶、双手举杯、茶碟旋转 |
| 05 | 抛接杂技 | 帽子降落、脚踢文件、单脚抛接、空中接食、谢幕 |
| 06 | 巨型文件战 | 负重接住、全身推挤、刀叉切块、坐在文件堆进食、撑肚拖行 |

这些图片是五关键姿势概念分镜，不是程序运行图集。正式制作时，每个方案需要独立补成完整连续动画，不能从其他方案随机拼接动作。
