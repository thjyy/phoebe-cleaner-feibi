## Phoebe Cleaner v0.4.1

这是针对 V10 正面故事动画的视觉修复版本。

### 修复内容

- “独立贪吃帽子”三段动画中的菲比改为不戴帽子，画面中只保留一顶有生命的独立帽子。
- “文件果汁车”退场的大位移阶段改用单角色刚性移动，消除光流补帧造成的双菲比重影。
- 重新烘焙 V10 动画图集与 README 动图预览。

### 安装

下载并运行 `PhoebeCleaner-Setup-v0.4.1.exe`。安装器按当前用户安装，无需管理员权限，并自动注册“召唤菲比来清理”右键菜单与“菲比清理设置”快捷方式。

### Windows 提示

当前安装包尚未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，可在核对本 Release 页面提供的 SHA-256 后选择“更多信息”继续运行。
