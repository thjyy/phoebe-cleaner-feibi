## Phoebe Cleaner v0.4.0

首个提供单文件 Windows 安装器的正式版本。

### 主要更新

- 新增六套动作机制完全不同的 V10 正面完整故事：贪吃帽子、文件果汁车、逃跑文件追逐、魔法下午茶、空中特技投食和大文件 Boss。
- V10 每段提升到 57 帧，每套完整流程共 171 帧；按文件大小动态延长处理动作，超大文件不设时长上限。
- 普通文件动画分布调整为 V10 50%、V8/V9 10%、V6 40%，并继续避免连续重复。
- 单个文件达到 256 MiB 时自动触发“大文件 Boss”。
- 保留准确的资源管理器选中项定位、多选/空文件夹/失败反应彩蛋，以及回收站删除机制。

### 安装

下载并运行 `PhoebeCleaner-Setup-v0.4.0.exe`。安装器按当前用户安装，无需管理员权限，并自动注册“召唤菲比来清理”右键菜单与“菲比清理设置”快捷方式。

如果资源管理器仍缓存旧菜单，请关闭并重新打开资源管理器窗口；极少数情况下需要重启 Explorer 或注销一次。

当前安装包尚未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，可在核对本 Release 页面提供的 SHA-256 后选择“更多信息”继续运行。
